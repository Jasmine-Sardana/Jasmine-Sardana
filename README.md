## Featured Projects


### Customer Support Ticket Classification

An NLP-based machine learning system that predicts customer
support ticket types and priorities from support text.

**Tech:** Python, NLP, TF-IDF, Logistic Regression, SVM, Scikit-learn

- Performed exploratory data analysis and text preprocessing.
- Built TF-IDF features using unigrams and bigrams.
- Developed classification models for ticket type and priority.
- Achieved **86.43% test accuracy for ticket type classification using SVM**.
- Exploring transformer-based models for further improvement.
